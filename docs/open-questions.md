## WhatsApp through Kapso (first-hour test)

From [ADR 0020](decisions/0020-whatsapp-via-kapso.md). A teammate is testing Kapso now; record the answers here, then update [integrations.md](architecture/integrations.md#whatsapp) and the `KAPSO_*` names in [setup.md](implementation/setup.md#environment-variables).

- [ ] **The free US number:** is it dedicated to us, and does it deliver inbound messages as webhooks to our backend (not only to Kapso's inbox)? Or is the sandbox all we get?
- [ ] **Recipient limit:** how many different phones can talk to the number (the sandbox only messages the registered recipient)? The demo needs both builders and the furniture owner.
- [x] **Payload format:** Kapso's own v2 shape (`message`, `conversation`, `phone_number_id`), not Meta's `entry/changes` envelope. Details in [integrations.md](architecture/integrations.md#kapso-as-built-confirmed-2026-10-17-kapso-sandbox).
- [x] **Auth and config names:** API auth is the `X-API-Key` header; webhooks are signed in `X-Webhook-Signature` (hex HMAC-SHA256 of the raw body). The env vars are `KAPSO_API_KEY`, `KAPSO_WEBHOOK_SECRET`, `KAPSO_PHONE_NUMBER_ID` ([setup.md](implementation/setup.md#environment-variables)).
- [x] **Media download:** confirmed live (2026-10-17, Kapso sandbox): `ChannelPort.download_media` works on the documented two-step (`GET /meta/whatsapp/v24.0/{media_id}?phone_number_id=…` → `download_url`, [research/voice-notes.md](research/voice-notes.md#downloading-the-audio)), checked with `uv run pytest -m live` and end to end with a photo and a voice note. `GET kapso.media_url` with `X-API-Key` also returns the bytes and stays on `InboundMessage` as a fallback.
- [x] **Voice-note transcript:** `message.kapso.transcript.text` arrives in the first webhook (a test voice note came back transcribed on the free sandbox, and the echo showed it end to end). Still unchecked: quality on real Rioplatense Spanish and plan limits ([ADR 0021](decisions/0021-voice-notes-kapso-transcript-gemini-fallback.md)).
- [ ] If any of these fails within the hour: switch to plan B (Meta Cloud API direct, ~1 h setup, max 5 recipients on the test number).

## Post images generated by AI (ADR 0018)

From [ADR 0018](decisions/0018-ai-image-generation-service.md). Hands-on checks for the providers (fidelity, cost, latency, no text, rate limits, crop) are listed in [research/image-generation-providers.md](research/image-generation-providers.md#open-points-test-hands-on-before-committing).

- [x] **Image generation provider:** Google Gemini `gemini-nano-banana-2.1`, with OpenAI `gpt-image-2.5-sunburst` as fallback ([ADR 0019](decisions/0019-image-provider-gemini.md)).
- [ ] **Number of variations per request.** Each is a paid call and adds latency. WhatsApp allows at most 3 reply buttons, so more than 3 variations means picking by text.
- [ ] **How the Owner picks a variation:** number buttons, a reply in text ("la 2"), or both, and the exact Spanish copy. Draft in [conversation-design.md](product/conversation-design.md) (`post_variations`).
- [x] **Source of "current trends"** for the Art Director's trend notes: the weekly Niche Report from the niche's reference websites and Google Search ([ADR 0025](decisions/0025-weekly-niche-report.md), options in [research/niche-trend-sources.md](research/niche-trend-sources.md)).
- [ ] **Copywriter hashtag rule**: the Copy contract asks for 10–20 hashtags, but Instagram caps posts at 5 and hashtags now correlate with lower reach. Drop to ≤ 5 plus a keyword-rich first line? See [research/instagram-content-trends.md](research/instagram-content-trends.md#implications-for-build101).
- [x] **Weekly niche analysis**: in the MVP as Should; the Owner sees it on request ([ADR 0025](decisions/0025-weekly-niche-report.md)).
- [ ] **Niche Report quality**: is Gemini's URL context and Google Search good enough for a Uruguayan niche in Spanish? Run it by hand on curated solid-wood furniture before building ([ADR 0025](decisions/0025-weekly-niche-report.md)). A first run on 2026-10-18 (La Ibérica and KATEI sites, `gemini-3.8-flash`) got `429 too_many_requests`: the key is on the **Free Tier**, limited to 20 requests per day for `gemini-3.8-flash`, and Google Search grounding isn't on the free tier for Gemini 3+ ([pricing](https://ai.google.dev/gemini-api/docs/pricing)). The run needs a key from a project with billing linked.
- [ ] **Reference websites per niche**: which stores' sites the Niche Analyst reads, and whether the Owner can add their own (wizard field or chat). First list in [research/furniture-decor-uruguay.md](research/furniture-decor-uruguay.md#reference-websites).
- [ ] **Per-post photos vs. the photo library:** do the photos the Owner sends with a request replace the Business's library as references for that Post, or complement it? Interim default in the docs: only the Owner's photos when they sent some (Art Director post-validation, T14).
- [x] **The Owner's logo on the image:** yes, when the Owner asks: code stamps the uploaded file in the bottom-right corner, and prompts still forbid drawing a logo ([ADR 0027](decisions/0027-owner-logo-stamped-in-code.md)). Still open: the simple text logo of F2.9 (Could), and uploading the logo from the chat.
- [ ] **Photos in the live request:** [ADR 0016](decisions/0016-demo-scope-one-post.md) words the demo as "a photo" → one preview, while ADR 0018 assumes a set of photos (around 10) → several variations → a pick. The stage now follows ADR 0018 ([mvp.md](product/mvp.md#demo-goal)); how many photos the live request uses is open.
- [ ] **Daily generation cap:** `MAX_POSTS_PER_DAY` defaults to 5 per Business ([agents.md](architecture/agents.md#when-image-generation-runs)). Is that right for the demo and for a real Owner, and does a slide redo count against it?
- [ ] **Time per post:** the old < 45 s target was for rendered templates; set a new one after measuring generation latency.

## Carousels (ADR 0022)

From [ADR 0022](decisions/0022-carousels-in-mvp.md).

- [x] **Carousels in the MVP:** Must, one per request, designed slides with text from the Copywriter, consistency by anchoring on the cover, slide redo instead of Variations.
- [x] **Gemini call shape:** `generateContent` (`client.aio.models.generate_content`), not the Beta Interactions API ([integrations.md](architecture/integrations.md#image-generation)).
- [ ] **Text check accuracy:** does a `low`-thinking Gemini vision call catch a misspelled or extra word reliably, and does it flag correct slides as wrong? Measure on the first real carousels.
- [ ] **Misspelling fallback:** a slide that still fails after its one regeneration is kept and flagged. Is it sent to the Owner as is, sent with a warning, or held back? And what if the cover fails, since the other slides anchor on it?
- [ ] **Real latency and cost per carousel:** the ADR estimates $0.30 to $0.40 and 40 to 70 s for 5 slides at 2K; log `usage` and timings on the first calls, with `GEMINI_THINKING_LEVEL` at `minimal` and `medium`.
- [ ] **Zernio carousel publish:** does a `POST /v1/posts` with several image `mediaItems` publish an Instagram carousel from our public `renders` URLs? Not verified ([integrations.md](architecture/integrations.md#calls)); test once on the demo IG.
- [ ] **Redo feedback that changes the words** ("que la 3 diga envío gratis"): does `redo_slides` rewrite that slide's text with the Copywriter, or only its scene?
- [ ] **On stage:** does the demo script show a carousel? Carousels are Must, but [product/demo-script.md](product/demo-script.md) shows one image Post.

## Instagram import (ADR 0028)

From [ADR 0028](decisions/0028-read-instagram-with-our-meta-app.md); calls and limits in [integrations.md](architecture/integrations.md#reading-the-owners-instagram-adr-0028).

- [ ] **Captions and bio over Instagram Login:** Meta's docs label `caption` "Facebook Login only" and leave `biography` and `website` out of `/me`; Zernio returns captions on the same kind of connection. Connect the demo account with `INSTAGRAM=meta` and check what `/me` and `/me/media` return. Without captions the import still brings photos, but loses the voice signal.
- [ ] **Serving real businesses:** our Meta app reads only Instagram testers in development mode. Reading any Owner's account needs Advanced Access for `instagram_business_basic`, App Review and Business Verification. When to start it, and how long it takes.
