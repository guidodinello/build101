# Audit summary and plan

Entry point to the product and codebase audit of Neitor AI run on 2026-10-19: the verdict, what to fix before real Owners, a digest of each area, and a 2-week, 30-day and 90-day plan. It is part of the [2026-10 audit](README.md); every finding, with its evidence and verifier note, lives in one of the dimension docs listed under [Where the details are](#where-the-details-are). Code was read at commit `dc0bc01`. An independent adversarial reviewer checked each finding against the code and the cited sources; "adjusted" means the reviewer corrected its severity or details, and the severities below already include those corrections.

Conventions: amounts in `$` are USD and amounts in `$U` are Uruguayan pesos. In the "Where" columns and in code links, paths are relative to `backend/app/` unless they start with `backend/`, `frontend/`, `docs/` or name a root file. Findings that overlap across dimensions are merged into one row; a merged row takes the highest severity of its parts, and its Ids column links each finding to the doc that holds it. Every cost, latency and saving in this doc is an estimate (see the caveat under [Cost and models](#cost-and-models)).

## Executive summary

- **Health.** For a 2-person MVP the core is solid. Approval is decided in code ([ADR 0007](../../decisions/0007-approve-every-post.md)), the webhook checks an HMAC signature, every lookup is scoped to the sender, and the ports and adapters are clean ([security-privacy.md](security-privacy.md), [backend-architecture.md](backend-architecture.md)). Tests: 591 unit tests pass, 95 Postgres tests run in CI, ruff is clean, and 69 of the last 70 CI runs were green (audit observation, 2026-10-19; [platform-ops.md](platform-ops.md)). The weak spots are durability, operations and hackathon-era shortcuts, not the conversation logic.
- **The pilot cannot start safely yet.** Three blockers, all critical:
  - Every Owner's approved Post goes to one shared demo Instagram account ([PRD-1](product.md); [posts/publish.py:103-110](../../../backend/app/posts/publish.py), [ADR 0024](../../decisions/0024-mvp-single-demo-instagram-account.md)).
  - The only way in is the Kapso sandbox. It answers one registered phone and cannot send templates ([PRD-3](product.md); [Kapso sandbox guide](https://docs.kapso.ai/docs/how-to/whatsapp/use-sandbox-for-testing.md), read 2026-10-19).
  - The hosting plans are not production plans: the Railway Trial expires ([ADR 0017](../../decisions/0017-backend-host-railway.md)), Vercel Hobby is non-commercial only ([Vercel Hobby plan](https://vercel.com/docs/plans/hobby), read 2026-10-19), and Meta review has not started ([OPS-3](platform-ops.md)).
- **Silent failure is the main risk.**
  - Posts, images, usage caps and in-flight work live in process memory ([posts/store.py:63-73](../../../backend/app/posts/store.py), [media/public.py:11-27](../../../backend/app/media/public.py)), and Railway kills the process with a 0 s drain ([Railway deployments reference](https://docs.railway.com/reference/deployments), read 2026-10-19) on every push: about 70 commits in 3 days (69 to 71 commits on main from 2026-10-17 to 2026-10-19, by the auditor's and the verifier's counts; audit observation, 2026-10-19). Owners lose pending approvals, generations, publishes and brand onboarding without being told ([ARCH-1](backend-architecture.md), [BUG-2](bugs-reliability.md), [OPS-1](platform-ops.md)).
  - There is no error tracking, no alerting and no backups ([OPS-4](platform-ops.md), [OPS-7](platform-ops.md)).
- **Security and compliance.** Supabase's anon role can read and write every table: RLS is off ([0001_initial.sql](../../../backend/migrations/versions/0001_initial.sql), confirmed by the live Supabase security advisor, audit observation 2026-10-19), and the public repo publishes the project ref, so one leaked anon key would expose everything ([SEC-1](security-privacy.md)). There is no privacy policy, consent, terms, deletion path or URCDP registration, which [Ley 18.331](https://www.impo.com.uy/bases/leyes/18331-2008), Meta and the [WhatsApp Business Messaging Policy](https://whatsappbusiness.com/es-la/policy/) all require (read 2026-10-19; [SEC-3](security-privacy.md)).
- **AI quality.** The Orchestrator loop is good, but the factual guarantees exist only in prompts: materials, prices and expired promos are not checked in code ([AIQ-3](ai-quality.md), [AIQ-4](ai-quality.md), [AIQ-15](ai-quality.md)). The message "¿Te gusta? ¿Lo subo?" combined with praise words in the yes-list can publish a Post on "genial" ([AIQ-8](ai-quality.md); [conversation/approval.py:43-51](../../../backend/app/conversation/approval.py)). Revisions regenerate every scene ([AIQ-7](ai-quality.md)). There is no eval harness, while prompts change every day ([AIQ-5](ai-quality.md)).
- **Unit economics verdict** (estimates; [unit-economics.md](unit-economics.md)).
  - A typical Basic Owner costs about $14-17 a month in variable cost, a 42-51% gross margin at $29 before about $80-90 a month of fixed cost.
  - There is no cost ceiling: a heavy user can cost over $100 a month ([COST-2](unit-economics.md)). gemini-3.8-flash also doubles in price on 2027-01-01 ([Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing), read 2026-10-19).
  - Quotas plus five mostly-small levers bring the margin to about 80%. Nothing is metered yet, so measure first ([COST-1](unit-economics.md)).
- **Biggest opportunities.**
  - Choose one Instagram connection per Owner. Zernio already covers import, publishing, inbox and insights, so per-Owner publishing and Pro can ship without Meta App Review ([GAP-1](cross-cutting-gaps.md); needs an ADR, related to [ADR 0024](../../decisions/0024-mvp-single-demo-instagram-account.md) and [ADR 0028](../../decisions/0028-read-instagram-with-our-meta-app.md)).
  - Targeted revisions: cheaper, faster, and a better experience for the Owner ([AIQ-7](ai-quality.md), [COST-6](unit-economics.md)).
  - A proactive loop (Monday plan, scheduling, results) to drive retention ([PRD-9](product.md), [PRD-10](product.md), [PRD-11](product.md)).
  - Offer a first Post at the end of onboarding to drive activation ([PRD-5](product.md), [GRW-11](growth-pricing-market.md)).
  - Route each agent to its own model before 2027-01-01 ([MOD-2](models.md), [MOD-1](models.md)).
  - Restate the moat: [Postou.ai](https://postou.ai/) (read 2026-10-19) already runs the same WhatsApp loop in Brazil at about $9 for 12 posts ([GRW-4](growth-pricing-market.md)).

## Cost and models

> **Every figure in this section is an estimate.** The numbers come from call counts derived from the code, the team's one measured carousel run, and list prices read on 2026-10-19. Cached tokens and image usage are not logged ([COST-1](unit-economics.md)), so the cache hit rate is modelled at both 0% and 70%. Replace these numbers with measured `agent_runs` data within a week. Full tables: [unit-economics.md](unit-economics.md) and [models.md](models.md).

- **Unit costs** (cache 0% / 70%, including WhatsApp messages, excluding Zernio, fixed platform cost, payment fees and IVA): a Post using the photos as they are $0.29 / $0.17, a single-image design Post $0.36 / $0.24, a 5-slide design Carousel $0.67 / $0.56 (about $0.38 optimized), an image "Cambiar" on a 5-slide Carousel $0.47, a chat turn $0.047 / $0.027, onboarding with an Instagram import of 27 photos $0.22.
- **Per Owner per month**: a typical Basic Owner (9 carousels, 3 designs, 3 photo Posts, 3 revisions, 40 chats) costs $16.87 / $14.10, or $5.89 optimized: a 42% / 51% margin at $29, about 80% optimized. A heavy Owner using what today's 5-designs-a-day cap allows costs $130 / $107, about $8-10 with a monthly quota ([COST-2](unit-economics.md)). Of a Basic Owner's $14.10, Zernio takes $4.80, images $3.90, WhatsApp $2.28 and the Orchestrator $2.05. The fixed floor once charging is about $80-90 a month, so break-even is about 4 Basic Owners ([COST-10](unit-economics.md)); if $29 includes IVA, today's margin drops to about 29-41%. Free-plan ceilings: Kapso Free runs out at about 10 active Owners, WhatsApp's 1,000 free service messages per number at about 5 Basic Owners ([GRW-19](growth-pricing-market.md)), and Gemini Tier 1's $250 cap at about 35 Basic Owners.

## How the audit was done

- **Agents**: 25 in all. 11 dimension auditors (unit economics, models, AI quality, product, growth and market, backend architecture, bugs and reliability, security and privacy, frontend, platform and ops, docs and process), an adversarial verifier for each dimension, a completeness critic whose findings form the 12th dimension (cross-cutting gaps) plus a verifier for it, and one synthesis.
- **Verification**: each verifier re-checked every finding against the code and the cited sources. Of 226 findings raised, 1 was refuted, 156 were adjusted (severity or details corrected) and 69 were confirmed. 225 were kept: 3 critical, 27 high, 110 medium and 85 low.
- **Baseline**: code read at commit `dc0bc01`; prices, terms and product pages read on 2026-10-19.
- **Merging**: findings that overlap across dimensions were merged in the synthesis, and a merged item takes the highest severity of its parts.
- **Limits**: costs, latencies and savings are estimates built from the code, the team's one measured carousel run and list prices, not measurements. No live service was changed. The only live-system reads were read-only Supabase checks (the security advisor and table-privilege queries) and GitHub repository metadata (CI run history and the branch ruleset); the test suite ran locally with live tests excluded (audit observation, 2026-10-19).
