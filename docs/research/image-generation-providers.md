# AI image generation providers

Question: which third-party image model can take the Owner's ~10 real product photos plus a Brand Brain and trend brief, and return several themed 1080x1350 (4:5) Instagram feed images that still show the real product, callable from our Python backend during a 24h hackathon?

This supports [ADR 0018](../decisions/0018-ai-image-generation-service.md), which defers the provider choice, and [ADR 0019](../decisions/0019-image-provider-gemini.md), which picks Gemini Nano Banana 2.1 with OpenAI GPT Image 2.5 as fallback (both `proposed`). Everything below was read on 2026-10-17 from each vendor's own docs, pricing and terms pages (links inline). Prices, limits and model names change often (several models listed here shipped in 2026), so re-check before relying on them. Nothing here was tested hands-on: no accounts were created and no paid API was called.

## Google Gemini (Nano Banana)

- **Models** ([image generation docs](https://ai.google.dev/gemini-api/docs/image-generation)): `gemini-nano-banana-2.1` (current recommended workhorse), `gemini-3.1-flash-image` (Nano Banana 2, previous generation), `gemini-3-pro-image` (Nano Banana Pro, premium), `gemini-3.1-flash-lite-image` (Lite). `gemini-2.5-flash-image` is deprecated and shut down on 2026-10-02 ([pricing](https://ai.google.dev/gemini-api/docs/pricing)); do not build on it.
- **References**: Nano Banana 2.1 and 3.1 Flash take up to 10 object images "with high-fidelity" plus up to 4 character images; Pro takes only 6 objects (plus 5 characters, 3 style refs); Lite takes 14 objects but is "Not optimized for multiple reference inputs" and only supports 1K, so it fails our requirements ([docs](https://ai.google.dev/gemini-api/docs/image-generation)). With ~10 product photos, 2.1 fits exactly; Pro would need us to pick the best 6.
- **Size**: 4:5 is native. At 1K it is 928x1152, below 1080x1350; at 2K it is 1856x2304 ([docs](https://ai.google.dev/gemini-api/docs/image-generation)). 1856/2304 ≈ 0.806, so the backend needs a small resize + crop (e.g. Pillow) to land on exactly 1080x1350. ADR 0018 says the backend "never composes images" and allows this resize and crop.
- **Price** (read 2026-10-17, [pricing](https://ai.google.dev/gemini-api/docs/pricing)): Nano Banana 2.1 output images $30/1M tokens = $0.0336 (1K), **$0.0504 (2K)**, $0.113 (4K); input $1.50/1M tokens; thinking billed as text output at $7.50/1M. Batch is half price but up to 24h turnaround, not usable in the chat flow. Nano Banana Pro: $0.134 per 1K/2K image, input ≈ $0.0011 per image. Thinking defaults to `medium` on 2.1 and can be set to `minimal` ([docs](https://ai.google.dev/gemini-api/docs/image-generation)). The cost of 10 input images plus thinking per variation is not documented as a per-image figure: measure it from the response usage.
- **Text**: advertised as strong ("Advanced text rendering"); there is no parameter to disable text, the docs' own prompts use "No text." ([docs](https://ai.google.dev/gemini-api/docs/image-generation)). All outputs carry an invisible SynthID watermark (same page).
- **API**: `pip install google-genai`, `client.interactions.create(model=..., input=..., response_format={"type": "image", "aspect_ratio": "4:5", "image_size": "2K"})`, synchronous, image returned base64 ([docs](https://ai.google.dev/gemini-api/docs/image-generation)). Corrected 2026-10-17: we call `generateContent` instead, and this `response_format` snippet doesn't match the SDK; see [Verified 2026-10-17](#verified-2026-10-17-docs--sdk-source-not-hands-on) below. The model "won't always follow the exact number of image outputs" asked for (Limitations, same page), so request one image per call and run variations in parallel. No official latency figure.
- **Limits**: per project; Tier 1 needs a linked billing account and has a $10 per 10-minute spend limit and $250 billing cap ([rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)). Per-model images-per-minute for Nano Banana 2.1 is not listed on that page (not verified; visible in AI Studio once the project exists).
- **Data** ([Gemini API terms](https://ai.google.dev/gemini-api/terms)): on Paid Services Google "doesn't use your prompts (including ... images ...) or responses to improve our products" and logs them "for a limited period of time" for abuse detection (no number given). Unpaid use (AI Studio, free quota) **is** used for training and may be read by human reviewers: do not upload real Owner photos without billing enabled.

### Verified 2026-10-17 (docs + SDK source, not hands-on)

A second read of Google's docs and of the `google-genai` SDK source on 2026-10-17, for [ADR 0022](../decisions/0022-carousels-in-mvp.md). Still no paid call was made.

- **Model:** `gemini-nano-banana-2.1` is stable and the recommended image model ([model page](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1)).
- **Which API:** use `generateContent` (`client.models.generate_content`, async `client.aio.models.generate_content`). The Interactions API (`client.interactions.create`) shown first in the [image generation docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation) is Beta, may have breaking changes, and stores interactions for 55 days by default.
- **The docs' Python snippet is wrong for the SDK:** `response_format={...}` is not how the Python SDK takes the size; use `config=GenerateContentConfig(response_modalities=["TEXT", "IMAGE"], image_config=ImageConfig(aspect_ratio="4:5", image_size="2K"))`, with an uppercase `K` in `"2K"` ([docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation), [python-genai](https://github.com/googleapis/python-genai)).
- **4:5 sizes:** 1K = 928×1152, 2K = 1856×2304, 4K = 3712×4608 ([docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)).
- **Inputs:** up to 14 reference images (10 objects + 4 characters); inline request ≤ 20 MB in total; PNG, JPEG, WEBP, HEIC and HEIF accepted; each input image costs 258 tokens per 768×768 tile ([docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)). That is why we downscale references to ≤ 1536 px JPEG before sending them.
- **Thinking:** `thinking_level` is `minimal`, `medium` (default) or `high`; it cannot be disabled. The model may return up to 2 interim thought images, which are not charged; they come as parts with `thought = true` and must be skipped ([docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)).
- **Retries:** in SDK `google-genai` 2.31.0, `HttpOptions.retry_options` defaults to `None`, so the client does **not** retry, although the troubleshooting page suggests it does; set `HttpRetryOptions` explicitly ([python-genai](https://github.com/googleapis/python-genai)).
- **Errors and finish reasons:** no image comes back with `finish_reason` `IMAGE_SAFETY`, `IMAGE_PROHIBITED_CONTENT`, `IMAGE_RECITATION`, `IMAGE_OTHER` or `NO_IMAGE` (or a `prompt_feedback.block_reason`); HTTP failures raise `ClientError` (4xx) and `ServerError` (5xx) ([python-genai](https://github.com/googleapis/python-genai), [docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)).
- **Iterating:** multi-turn chats are Google's recommended way to edit an image step by step, and the SDK handles thought signatures, but carousel slides would then run one after another ([docs](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)). ADR 0022 anchors on the cover instead.
- **Batch:** half price, but up to 24 h turnaround ([pricing](https://ai.google.dev/gemini-api/docs/pricing)); not usable in the chat flow.
- **Rate limits:** no published images-per-minute figure for 2.1 ([rate limits](https://ai.google.dev/gemini-api/docs/rate-limits)).
- **Latency:** no official figure. A third party (Eden AI) reports about 11–13 s median and 19–24 s p95 per image; secondary source, not verified.
- **Conflicts between Google's pages:** the 4K output token count differs between pricing tables (2520 vs 3780 tokens) ([pricing](https://ai.google.dev/gemini-api/docs/pricing)), and the `gemini-2.5-flash-image` shutdown date is 2026-10-02 on one page and 2027-03-15 on another ([pricing](https://ai.google.dev/gemini-api/docs/pricing), [deprecations](https://ai.google.dev/gemini-api/docs/deprecations)). Neither affects us at 2K on 2.1.

## OpenAI GPT Image

- **Models** ([guide](https://developers.openai.com/api/docs/guides/image-generation)): `gpt-image-2.5-sunburst` ("workflows where editing precision matters most") and `gpt-image-2.5-flare` (fast everyday generation); older `gpt-image-2`, `gpt-image-1.5`, `gpt-image-1`, `gpt-image-1-mini` remain.
- **References**: `POST /v1/images/edits` accepts "up to 16 images", each png/webp/jpg under 50 MB; `n` between 1 and 10 outputs per call ([images.edit reference](https://developers.openai.com/api/reference/python/resources/images/methods/edit)). The guide shows composing a new image from 4 reference product images. `input_fidelity` is fixed to high on `gpt-image-2` ("omit this parameter"); the reference does not say how it applies to the 2.5 models (not verified).
- **Size**: custom `WIDTHxHEIGHT`, both edges multiples of 16, ratio within 1:3–3:1, 655,360–8,294,400 total pixels ([guide](https://developers.openai.com/api/docs/guides/image-generation)). 1080x1350 is not a multiple of 16; `1088x1360` is exactly 4:5 and valid, then downscale.
- **Price** (read 2026-10-17, [pricing](https://developers.openai.com/api/docs/pricing)): 2.5 models charge $8/1M image input tokens, $5/1M text input, $30/1M image output tokens (Batch half). The model page says the GPT Image 2 calculator "does not estimate GPT Image 2.5 token consumption" ([gpt-image-2.5-flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)), so we have **no verified per-image price**; measure from `usage`. On the Images API, cached-input pricing does not apply to `/v1/images/edits` ([guide](https://developers.openai.com/api/docs/guides/image-generation)).
- **Text and limits**: docs list text placement, brand-element consistency across generations and precise composition as known limitations; latency "up to 2 minutes" for complex prompts; `jpeg` output is faster than `png` ([guide](https://developers.openai.com/api/docs/guides/image-generation)). Rate limit for a new (Build tier) account: 20 images per minute, 250,000 TPM ([gpt-image-2.5-flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)).
- **Data** ([your data](https://developers.openai.com/api/docs/guides/your-data)): API data "is not used to train or improve OpenAI models (unless you explicitly opt in)"; `/v1/images/edits` abuse logs retained 30 days.
- **Signup**: "you may need to complete the API Organization Verification" before using GPT Image models ([guide](https://developers.openai.com/api/docs/guides/image-generation)). It is a manual step with uncertain turnaround; do it before the hackathon, not during.

## Black Forest Labs (FLUX)

- **Models**: FLUX 3 Image (`/v1/flux-3-image`, generate + edit, up to 10 references), FLUX 3 Klein (cheap), FLUX.2 `[pro]`/`[max]`/`[flex]` (up to 8 references via API, 4 for `[klein]`), and FLUX.1 Kontext (previous generation) ([FLUX 3 Image](https://docs.bfl.ml/flux_3/flux3_image_overview), [FLUX.2 overview](https://docs.bfl.ml/flux_2/flux2_overview)).
- **Size**: `aspect_ratio` enum includes `4:5`; `resolution` tiers `768sq`, `1k` (~1 MP, below 1080x1350), `1.5k` (~2 MP), `2k` (~4 MP), `4k`; "Exact dimensions vary with the aspect ratio" ([API reference](https://docs.bfl.ml/api-reference/utility/generate-an-image-with-flux-3)). Reference images must be ≥256x256 and ≤16 MP ([generate docs](https://docs.bfl.ml/flux_3/flux3_image_generate)).
- **Price** (read 2026-10-17, from the published pricing data that [the pricing page](https://docs.bfl.ml/quick_start/pricing) renders; 1 credit = $0.01): FLUX 3 Image $0.048 (1k), **$0.07 (1.5k)**, $0.10 (2k); FLUX 3 Klein $0.011 at 1.5k; FLUX.2 `[pro]` $0.03 first output MP + $0.015 per extra output MP **and** $0.015 per input MP, so 8 references cost more than the output; FLUX.1 Kontext `[pro]` $0.04.
- **API**: REST with `x-key` header; asynchronous: submit returns `polling_url` and `cost`, poll until `Ready`, download `result.sample` within 1 hour; `result.duration` reports generation seconds ([generate docs](https://docs.bfl.ml/flux_3/flux3_image_generate)). Max 24 concurrent requests on most endpoints ([integration guidelines](https://docs.bfl.ml/api_integration/integration_guidelines)). No official Python SDK in the docs examples (plain `requests`).
- **Data**: the FLUX API Service Terms (last revised 2026-08-04, non-EU version) grant BFL a "perpetual, irrevocable" license and state the Company "may use Inputs and Outputs to train and improve its artificial intelligence models"; no opt-out found on that page ([API terms](https://bfl.ai/legal/flux-api-service-terms)). This is the main reason not to make BFL primary: the Owner's product photos would become training data.

## Aggregators: fal.ai and Replicate

- **fal.ai** hosts Nano Banana 2 / Pro, GPT Image 2, FLUX 3 Image and many open models behind one key ([pricing](https://fal.ai/pricing)). Nano Banana 2 edit is $0.08 per image, 2K billed at 1.5x ($0.12), 4K at 2x ([model page](https://fal.ai/models/fal-ai/nano-banana-2/edit)), i.e. more than Google direct at 2K. The $0.0398 "Nano Banana" row likely maps to the shut-down `gemini-2.5-flash-image` (not verified). Promotional credits expire in 90 days; the terms allow using anonymized/aggregated "Usage Data ... derived from Customer Input" to develop AI models ([terms](https://fal.ai/terms)). Free-credit amounts and card requirements come only from third-party sites that contradict each other: not verified.
- **Replicate** hosts the official `google/nano-banana-2` (14 references, `4:5` listed) ([model page](https://replicate.com/google/nano-banana-2)); its pricing page does not list a price for it ([pricing](https://replicate.com/pricing)). API inputs, outputs and logs are "automatically removed after an hour, by default" ([data retention](https://replicate.com/docs/topics/predictions/data-retention)).
- **Use**: an aggregator is a useful one-key switch between models during prompt tuning, but adds a second processor of the Owner's photos and a markup. Not needed if we call one vendor directly.

## Not evaluated in depth

- **Ideogram, Recraft, Stability AI**: one search for Ideogram's reference-image limits returned only third-party wrappers that disagree on field names; Recraft and Stability were not checked. We did not confirm whether any of them supports ~10 product reference images per request, so they are left out rather than ruled out.

## Independent evidence on fidelity

- All "high-fidelity object" claims above are **vendor marketing**. We found no independent benchmark of multi-reference **product identity** preservation.
- The closest public signal is the crowd-voted Arena image-edit leaderboard, which measures single-image edits, not product fidelity. arena.ai returned HTTP 403 to our fetch; a third-party snapshot dated 2026-09-22 lists `gpt-image-2.5-sunburst` first and Gemini models below it ([benchmarklist snapshot](https://benchmarklist.com/arenas/arena_ai_image_edit/), secondary source, not verified against arena.ai). Treat this as weak evidence; our own test with real furniture photos is what counts.

## Recommendation for the hackathon

- **Primary: Gemini Nano Banana 2.1** (`gemini-nano-banana-2.1`). It is the only option where every requirement the docs can answer checks out from primary sources (fidelity still needs our own test): 10 high-fidelity object references (our exact batch size), native 4:5 at 2K, a verified **$0.0504** output price, a synchronous official Python SDK, and no training on paid-tier data. Friction is a Google Cloud billing account.
- **Fallback: OpenAI `gpt-image-2.5-sunburst`** via `/v1/images/edits`. Different vendor, so an outage or a moderation block on one does not stop the demo; 16 references, exact `1088x1360`, no training, 30-day retention. Trade-off: per-image cost not verifiable from docs, up to 2 minutes per complex image, and Organization Verification must be finished before the event.
- **Not primary: FLUX 3 Image.** Good fit technically (10 references, `4:5`, $0.07 at 1.5k) but its default API terms let BFL train on the Owner's photos.
- Keep the choice behind `ImageGenPort` (ADR 0018) so switching is a config change.

## Open points (test hands-on before committing)

- [ ] **Real cost per variation**: log `usage` for 10 input images + prompt (+ thinking on Gemini, try `minimal`) and compute $ per variation; OpenAI 2.5 per-image cost is only knowable this way.

- [ ] **Carousel text and consistency** ([ADR 0022](../decisions/0022-carousels-in-mvp.md)): how often 2.1 renders a slide's exact text, and whether anchoring on the cover keeps 5 slides in one visual style.
- [ ] **Rate limits** for a new Tier 1 Gemini project (images per minute for 2.1 is not on the public page) and OpenAI Build tier (20 IPM).
- [ ] **Resize step**: confirm the downscale/crop to 1080x1350 keeps the product in frame.
- [ ] **Signup**: Gemini billing account and OpenAI Organization Verification done before the hackathon; whether Google Cloud free-trial credits pay for Nano Banana is not verified.
